Export a backup before changing browser or device. A backup includes expenses, categories, settings, and bill pictures.

Restoring a backup replaces the data currently in this browser. Export a backup of your current data first if you may need it.

About your data

Everything is stored locally in this browser using localStorage. No account or server is required, and the app does not send your expense records anywhere.

  • Data is tied to this browser and device; it does not automatically sync with other people or devices.
  • Clearing browser site data, using private browsing, or browser storage limits can remove records. Bill images use extra storage.
  • This is a personal local tool, not a secure multi-user system. Anyone with access to this browser profile may be able to view your records.
  • Use the JSON backup regularly. Keep backup files somewhere private.
